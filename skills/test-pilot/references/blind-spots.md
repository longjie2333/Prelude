# 盲区清单

测试人员最容易漏掉的地方。每次测试至少过一遍：逐项判断是否适用，适用就至少设计一个探测。

| 盲区 | 探测方法 |
|---|---|
| 边界与异常路径 | 空值、0、负数、最大值和最大值 +1、超长字符串、缺字段、多余字段、类型错误、非法枚举值 |
| 并发与重复提交 | 同一操作并发执行 N 次；重复点击；重放同一请求；检查资源是否守恒（总量、余额、配额、计数） |
| 状态流转 | 非法转换（已完成再取消、未支付就发货）；重复转换；中途失败后的状态；回退 |
| 权限越权 | 改别人的 id（水平越权）；普通用户调管理接口（垂直越权）；未登录访问；token 过期后访问 |
| 输入编码与国际化 | 非 ASCII 文本、组合字符、RTL 文字、全角字符、特殊符号和控制字符；时区、日期与数字的本地化格式 |
| 错误提示与恢复 | 合法输入不应得到 5xx；错误码是否恰当（4xx 与 5xx）；提示是否泄露内部信息；失败后能否恢复 |
| 可访问性 | 键盘可达、焦点顺序、对比度、控件标签、读屏可读 |
| 性能退化 | 列表和分页在大数据量下的正确性与耗时；响应时间随数据增长；N+1 请求 |
| 配置与环境差异 | 不同环境的默认配置、特性开关、时钟与时区、缓存与一致性延迟 |

## 用法

- 分页、列表类接口：遍历所有页，检查并集是否等于总数、有无重复或缺失。
- 写操作：前后各读一次，检查不变量（守恒、幂等、单调）。
- 每个"不适用"也写进报告的"没测什么"，并说明原因。
